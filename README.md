# Hecto

A Rust terminal text editor built as a hands-on learning project,
following the [Hecto tutorial](https://www.flenker.blog/hecto/).

The first goal is to understand how a small terminal editor works by
implementing the tutorial in its original learning-oriented form. After
completing that stage, the project may be refactored and expanded into a
more capable code editor.

## Project goals

- Learn Rust through a practical, progressively built application.
- Understand terminal input, screen drawing, cursor movement, text
  buffers, and file handling.
- Practice readable code, incremental development, testing, and Git
  workflows.
- Build a foundation that can later evolve into a code editor.

## Learning roadmap

1.  Complete the Hecto tutorial as written, focusing on understanding
    each step.
2.  Review and test the completed tutorial implementation.
3.  Refactor the code into clearer, well-separated parts where
    appropriate.
4.  Gradually add code-editor capabilities, such as syntax highlighting,
    search, and other editing features.

## Getting started

Make sure Rust and Cargo are installed. Then clone the repository and
run:

```bash
cargo run
```

The command assumes the project has been set up as a Cargo package.
